# Internship Application Management System

## 👤 Developed By
Krishnendhu PA

## 📌 Problem Statement
An organization receives internship applications from multiple colleges every day. 
Currently, applications are stored but not analyzed properly, causing delays in shortlisting and communication.

This project builds a simple system to:
- Organize internship applications
- Identify incomplete entries
- Detect duplicate applications
- Generate a basic shortlist for faster hiring decisions

---

## 🚀 Features

✅ Reads internship applications from a CSV file  
✅ Detects incomplete applications  
✅ Identifies duplicate entries (based on Email)  
✅ Generates shortlist based on:
   - CGPA ≥ 8.0
   - Python skill
   - Full-time availability  
✅ Exports results into separate CSV files  

---

## 📂 Output Files Generated

- shortlisted.csv  
- incomplete.csv  
- duplicates.csv
